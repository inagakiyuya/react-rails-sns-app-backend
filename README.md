# react-rails-sns-app-backend
  ReactとRailsを用いたキャッチアップ用のSNS風アプリ(バックエンド)

# 実装機能一覧
-ログイン機能・サインアップ機能<br>
-投稿作成機能(文章・写真)<br>
-投稿に対するコメント機能<br>
-投稿に対して高評価・低評価をつける機能<br>
-お気に入りの投稿に対してタグをつける機能<br>
-投稿更新・削除機能<br>
-投稿一覧機能<br>
-フォロー機能<br>
-ユーザー検索機能<br>
-投稿検索機能<br>
-ユーザーブロック機能<br>
-マイページ機能<br>
  -アカウント編集機能<br>
  -自分の投稿一覧/高評価をつけた投稿一覧/お気に入りをした投稿一覧<br>

-今後入れるかもしれない機能<br>
 -パスワードリセット機能<br>
 -プレビュー機能<br>
 -通知機能<br>
 -管理者機能<br>
 -ハッシュタグ機能<br>
 -タイムラインの出しわけ<br>
 -検索時のオートコンプリート機能<br>
 -高評価やお気に入りをつけた投稿のカテゴリーを基におすすめの投稿を表示させる機能<br>
