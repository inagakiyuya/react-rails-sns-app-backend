# react-rails-sns-app-backend
  ReactとRailsを用いたキャッチアップ用のSNS風アプリ(バックエンド)

# 実装機能一覧
-ログイン機能・サインアップ機能
-投稿作成機能(文章・写真)
-投稿に対するコメント機能
-投稿に対して高評価・低評価をつける機能
-お気に入りの投稿に対してタグをつける機能
-投稿更新・削除機能
-投稿一覧機能
-フォロー機能
-ユーザー検索機能
-投稿検索機能
-ユーザーブロック機能
-マイページ機能
  -アカウント編集機能
  -自分の投稿一覧/高評価をつけた投稿一覧/お気に入りをした投稿一覧

-今後入れるかもしれない機能
 -パスワードリセット機能
 -プレビュー機能
 -通知機能
 -管理者機能
 -ハッシュタグ機能
 -タイムラインの出しわけ
 -検索時のオートコンプリート機能
 -高評価やお気に入りをつけた投稿のカテゴリーを基におすすめの投稿を表示させる機能
